# Fontes incorporadas ao Caderno

DM Sans (normal e itálico) e Caveat são distribuídas junto do aplicativo para uso offline.
Os arquivos originais, sem alterações, foram obtidos em 2026-10-29:

- DM Sans: https://github.com/google/fonts/tree/main/ofl/dmsans
- Caveat: https://github.com/google/fonts/tree/main/ofl/caveat

As licenças SIL Open Font License estão em `DM-Sans-OFL.txt` e `Caveat-OFL.txt`.
As demais famílias do seletor usam as fontes instaladas no sistema e alternativas locais.
