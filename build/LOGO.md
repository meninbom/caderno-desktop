# Marca do Caderno

Criada com a ferramenta integrada image_gen em 2026-10-29. PNG original em
`build/caderno.png`, cópia utilizada no aplicativo em `src/public/caderno.png`.
O ícone Windows `build/icon.ico` é gerado por `scripts/build-icon.cjs` usando o exportador
de imagens do Electron, com transparência e tamanhos 16, 24, 32, 48, 64, 128 e 256 px.
O aplicativo, o executável e o instalador usam a mesma marca.

## Prompt utilizado

Use case: logo-brand. Create one polished original application icon for Caderno, a local-first Windows desktop notes app. Output a single square 1024x1024 icon, centered and front-facing, with transparent outer background. An indigo-blue rounded square tile inset about 8% from canvas edges, containing an ivory/off-white stylized notebook mark. Integrate a subtle letter C into the notebook using negative space and a folded page or discreet bookmark. Deliberate clean geometric construction, bold silhouette instantly recognizable at 16, 24, 32 and 48 pixels. Premium restrained desktop app identity, flat vector-like forms with very subtle depth, high contrast. Keep all marks within safe icon padding. Color palette indigo #3157DC, deep blue #182A68, soft paper #F8FAFF, tiny cyan accent optional. No words, no lettering outside the abstract C notebook symbol, no labels, no watermarks, no mockup, no surrounding objects, no multiple alternatives, no thin delicate lines. Transparent background outside the rounded tile.
